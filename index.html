塞班 Java 游戏档案

记录 · 索引 · 网盘

这些游戏散在老论坛、老网盘和一堆叫不出名字的站里，链接一年比一年少。名字还在，能查的东西却越来越少。

这里做的是把这些名字重新整理成可检索的条目：一条对应一个作品，记下它的名称、版本号、适配分辨率，以及能查证到的发行商和年份。

文件不在站上，都在网盘里。每条记录里写着文件夹、编号和文件名，照着找就行。网盘里实在没有的，再去「下载」看看。

三个入口

查一条游戏

按名字、版本或分辨率搜索，也可以按类型和年份翻。目录 →

按编号取文件

网站不放安装包。每条都标了文件夹、编号和文件名，照着编号在网盘里找。怎么找 →

在自己手机上跑起来

J2ME-Loader 这类开源模拟器的资料与出处。工具 →
