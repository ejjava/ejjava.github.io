塞班 Java 游戏档案

记录 · 索引 · 不提供文件

这个站重新开始了 旧的那批下载记录已经全部清空。从今天起这里只做一件事：把塞班和 J2ME 时代的游戏名字、厂商、版本、适配分辨率，一条一条记下来。 站内不提供任何安装包，也不提供任何下载地址。

这一站在做什么

2001 年到 2012 年之间，中国人手里最多的智能终端不是 iPhone，是诺基亚。S40、S60、S80 那一批机器上有过一整个 Java 游戏生态：几 MB 的 .jar 文件，一点点像素，一个下午就能通关，却构成了很多人的移动游戏启蒙。

这个生态散得比想象中快。塞班系统 2013 年停止更新，应用商店陆续关停，当年的论坛、网盘、下载站一批批消失。留下的不是"资源"，是名字——很多游戏现在只剩下一串残名，厂商、年份、类型都已经查不到了。

这里做的是把这些名字重新整理成可检索的条目：一条一条对应一个作品，记录它的名称、版本号、适配分辨率，以及能查证到的发行商和年份。写的是书目，不是复制件。

如果你要找的是文件本身，这个站帮不上忙。下面的「友链」页列了几个仍在运营的第三方站点，那里才有下载。
