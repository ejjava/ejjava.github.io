本站只做记录，不存文件、不给下载地址。下面这些站点仍在运营，需要 .jar 文件的话点标题直接过去。

链接指向第三方站点，内容与安全性由对方负责，本站不做担保。站点失效请在帮助页留言。

  • J2MECloud 游软下载 收录 J2ME 游戏与软件资源，条目带截图与详情页，支持关键词检索。 j2mecloud.ddns.net:3092
  • 52模拟器 Java 游戏按类型分栏陈列，站内自带跨站搜索的几个入口。 java.52emu.cn
  • Java游戏小站 近六百条游戏的个人站点，附 Java 模拟器与塞班模拟器的资料。 java.owoemu.com
  • JVGME 带社区功能的 Java 游戏站，分类较细，浏览需要浏览器开启 JavaScript。 www.jvgme.com
  • JAVA游戏资料库 纯列表式的资料库，逐条编号可点，没有站内搜索，只能顺次翻。 jvgm.cc
  • 小众网 面向小众机型与软件的综合站，不专做 Java 游戏。 iniche.cn

前五个站点里，前三个的站内搜索已经在条目详情页接通了——从任意一条档案点「在 XX 搜索」，会直接带上这个游戏名跳到对方的搜索结果。JVGME 打开的是搜索页，关键词还要在页内输一次；JAVA游戏资料库没有搜索功能。
