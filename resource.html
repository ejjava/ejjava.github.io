工具与模拟器

运行 · 研究 · 不涉及游戏本体

下面收录的是运行、研究 J2ME 程序所需的开源模拟器与免费工具。这一页不涉及任何游戏文件。

移动端

  • J2ME-Loader Android 平台 J2ME 模拟器，支持大多数 MIDP 2.0 应用与常见分辨率，目前在维护、社区活跃。适合在新机型上做运行与存档验证。 github.com/nikita36078/J2ME-Loader

桌面端

  • FreeJ2ME Java 编写的开源 J2ME 模拟器，跨平台，可通过 Web 前端运行，适合批量验证与截图存档。 github.com/hex007/freej2me
  • MicroEmulator 老牌开源 J2ME 模拟器，MIDP 1.0 / 2.0 兼容性好，是早期开发者最常用的调试环境之一。 sourceforge.net/projects/microemulator

开发与打包

  • J2ME 技术规范 MIDP / CLDC 规范与开发文档的官方入口。若要做条目考据之外的复刻与自制，工具链从这里起步。 oracle.com/java/technologies
